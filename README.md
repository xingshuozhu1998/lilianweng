## 源码与译文

`main` 分支保存构建与翻译源码、术语表和翻译缓存；`gh-pages` 分支用于发布生成的静态网站。原站通过 `upstream/` 子模块固定，图片在中文与英文页面之间共享，避免重复保存近 400 MB 资源。
