## 来源与保留格式

`upstream/` 是 Git submodule（固定原作者仓库及版本的源码引用），来自 [原站仓库](https://github.com/lilianweng/lilianweng.github.io)，固定提交为 `95ba34c87d54bc406e3ba7de253ee3b9590b2ead`。该版本包含 2017-06-21 至 2026-07-04 的 52 篇文章；本次交付范围以该版本为准。

构建直接编辑原站静态 HTML 的文字位置，保留原页面元素顺序、段落、目录锚点、公式、代码、图片、蓝色更新说明及参考文献。中文与英文页面共用原资源，避免重复保存约 400 MB 图片等文件。图片内部文字保持原图，图注翻译成中文；公式与代码保留原样，英文论文题名与作者名保持可检索。被行内标签整体保护的图片替代文字和属性提示可能保留英文。

专有名词以及难以精确汉译的词组保留原始英文，以每篇标题和正文为范围，首次出现时紧跟括号内中文简释，后续继续使用英文。例如 `best-of-n（从 n 个候选中择优）`、`latent thoughts（潜在的思考过程）`、`harness（智能体运行框架）`。目录、参考文献、代码、公式和 HTML 属性不占用正文的首次说明；同一缩写在不同领域含义不同时按文章解释，如问答评估中的 `EM（完全匹配）` 与参数估计中的 `EM（期望最大化）`。

## 最短复核与本地构建

可用以下命令获取公开源码并复核：

```bash
git clone --recurse-submodules https://github.com/xingshuozhu1998/lilianweng.git
cd lilianweng
python3 -m pip install -r requirements.txt
python3 scripts/build.py extract
python3 scripts/build.py build
python3 scripts/check_site.py
```

在当前工作目录复核，只需最后三个命令。预期依次得到 **52 篇 / 10,555 个片段**、**缺失 0 个页面片段**、**52 篇通过 / 错误 0 / 警告 0**。输出网站位于 `dist/`。构建只依赖 Python 标准库；验收使用 `lxml`（解析 HTML 并对照原文结构的库）。源码、译文缓存和审核文件保存在 `main` 分支，生成网站发布至 `gh-pages` 分支。
