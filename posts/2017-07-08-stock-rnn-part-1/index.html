这是一篇介绍如何使用 Tensorflow（机器学习框架）构建 recurrent neural network（循环神经网络）来预测股票市场价格的教程。完整的可运行代码位于 github.com/lilianweng/stock-rnn。如果你还不了解 recurrent neural network 或 LSTM（长短期记忆网络）单元，可以阅读我之前的文章。

我想强调一点：写这篇文章的动机主要是演示如何在 Tensorflow 中构建并训练 RNN模型，而不是解决股票预测问题，因此我没有花太多精力改善预测结果。非常欢迎你以我的代码为参考起点，加入更多与股票预测有关的想法来改进它。希望你享受这个过程！

目标#

我将介绍如何构建使用 LSTM 单元的 RNN 模型，预测 S&P500（标准普尔500）指数的价格。数据集可以从 Yahoo! Finance ^GSPC 下载。在下面的示例中，我使用了从1950年1月3日（Yahoo! Finance 能追溯到的最早日期）到2017年6月23日的 S&P 500 数据。数据集为每一天提供了多个价格值。为了简单起见，我们只使用每日收盘价进行预测。同时，我将演示如何使用 TensorBoard，方便地调试并跟踪模型。

简单回顾一下：recurrent neural network（循环神经网络；RNN）是一种隐藏层中存在自循环连接的人工神经网络。这种连接使 RNN 能够在接收新输入时，利用隐藏神经元先前的状态来学习当前状态。RNN 擅长处理序列数据。Long short-term memory（长短期记忆；LSTM）单元是一种专门设计的工作单元，帮助 RNN 更好地记忆长期上下文。

想了解更深入的信息，请阅读我之前的文章或这篇出色的文章。

数据准备#

股票价格构成一个长度为 $N$ 的时间序列，定义为 $p_0, p_1, \dots, p_{N-1}$，其中 $p_i$ 是第 $i$ 天的收盘价，$0 \le i < N$。设想我们有一个固定大小为 $w$ 的滑动窗口（后文称为 input_size），每次将窗口向右移动 $w$，使所有滑动窗口中的数据彼此不重叠。

我们即将构建的 RNN 模型以 LSTM 单元作为基本隐藏单元。我们使用从最初的第一个滑动窗口 $W_0$ 到窗口 $W_t$ 的各个值，该窗口对应时间 $t$：

$$ \begin{aligned} W_0 &= (p_0, p_1, \dots, p_{w-1}) \\ W_1 &= (p_w, p_{w+1}, \dots, p_{2w-1}) \\ \dots \\ W_t &= (p_{tw}, p_{tw+1}, \dots, p_{(t+1)w-1}) \end{aligned} $$

来预测下一个窗口 $w_{t+1}$ 中的价格：

$$ W_{t+1} = (p_{(t+1)w}, p_{(t+1)w+1}, \dots, p_{(t+2)w-1}) $$

本质上，我们试图学习一个近似函数，$f(W_0, W_1, \dots, W_t) \approx W_{t+1}$。

考虑到 back propagation through time（通过时间反向传播；BPTT） 的工作方式，我们通常以“展开”的形式训练 RNN，从而不必将传播计算追溯到太久之前，降低训练复杂度。

以下是 num_steps 的解释，来自 Tensorflow 教程：

按照设计，recurrent neural network（循环神经网络；RNN）的输出依赖于任意久远之前的输入。遗憾的是，这会使反向传播计算变得困难。为了使学习过程易于处理，常见做法是创建网络的“展开”版本，其中包含固定数量（num_steps）的 LSTM 输入与输出。随后，在这个 RNN 的有限近似上训练模型。具体实现方式是每次馈入长度为 num_steps 的输入，并在每个这样的输入块之后执行一次反向传播。

首先将价格序列划分为互不重叠的小窗口。每个窗口包含 input_size 个数，被视为一个独立的输入元素。然后，将任意 num_steps 个连续输入元素组合成一个训练输入，形成 RNN 的“展开”版本，用于在 Tensorfow 中训练。相应的标签是紧接在这些元素之后的输入元素。

例如，如果 input_size=3 且 num_steps=2，那么最前面的几个训练示例如下：

$$ \begin{aligned} \text{Input}_1 &= [[p_0, p_1, p_2], [p_3, p_4, p_5]]\quad\text{Label}_1 = [p_6, p_7, p_8] \\ \text{Input}_2 &= [[p_3, p_4, p_5], [p_6, p_7, p_8]]\quad\text{Label}_2 = [p_9, p_{10}, p_{11}] \\ \text{Input}_3 &= [[p_6, p_7, p_8], [p_9, p_{10}, p_{11}]]\quad\text{Label}_3 = [p_{12}, p_{13}, p_{14}] \end{aligned} $$

下面是整理数据格式的关键部分：

seq = [np.array(seq[i * self.input_size: (i + 1) * self.input_size]) 
       for i in range(len(seq) // self.input_size)]

# Split into groups of `num_steps`
X = np.array([seq[i: i + self.num_steps] for i in range(len(seq) - self.num_steps)])
y = np.array([seq[i + self.num_steps] for i in range(len(seq) - self.num_steps)])

训练集与测试集划分#

因为我们始终希望预测未来，所以将时间上最近的10%数据作为测试数据。

归一化#

S&P 500 指数随时间上涨，这带来一个问题：测试集中的大多数值超出了训练集的数值范围，因此模型必须 预测一些它从未见过的数值。遗憾的是，它的表现惨不忍睹，而这也并不出人意料。请看

为了解决超出数值范围的问题，我对每个滑动窗口内的价格进行归一化。任务由此变为预测相对变化率，而不再预测绝对值。在归一化后的滑动窗口 $W’_t$ 中，其对应时间为 $t$，所有值都除以最后一个未知价格，即 $W_{t-1}$ 中的最后一个价格：

$$ W’_t = (\frac{p_{tw}}{p_{tw-1}}, \frac{p_{tw+1}}{p_{tw-1}}, \dots, \frac{p_{(t+1)w-1}}{p_{tw-1}}) $$

构建模型#

相关定义#

  • lstm_size：一个 LSTM 层中的单元数量。
  • num_layers：堆叠的 LSTM 层数。
  • keep_prob：在 dropout（随机丢弃） 操作中保留的单元比例。
  • init_learning_rate：初始学习率。
  • learning_rate_decay：训练后期各轮使用的衰减比例。
  • init_epoch：使用固定 init_learning_rate 的训练轮数。
  • max_epoch：训练的总轮数。
  • input_size：滑动窗口的大小，也就是一个训练数据点的大小。
  • batch_size：一个 mini-batch（小批量）中使用的数据点数量。

LSTM 模型堆叠了 num_layers 个 LSTM 层，每一层包含 lstm_size 个 LSTM 单元。然后，对每个 LSTM 单元的输出施加 dropout（随机丢弃） 掩码，其保留概率为 keep_prob。dropout 的目标是消除对某个维度可能存在的强依赖，从而防止过拟合。

训练总共需要 max_epoch 轮；一次 epoch（训练轮） 是完整遍历所有训练数据点一次。在一轮中，训练数据点被划分为大小为 batch_size 的 mini-batches（小批量）。每次向模型送入一个小批量，执行一次 BPTT 学习。学习率设为 init_learning_rate，并在前 init_epoch 轮保持该值；随后每一轮都按照 $\times$ learning_rate_decay 衰减。

# Configuration is wrapped in one object for easy tracking and passing.
class RNNConfig():
    input_size=1
    num_steps=30
    lstm_size=128
    num_layers=1
    keep_prob=0.8
    batch_size = 64
    init_learning_rate = 0.001
    learning_rate_decay = 0.99
    init_epoch = 5
    max_epoch = 50

config = RNNConfig()

定义计算图#

tf.Graph 不绑定任何真实数据。它定义数据处理与计算执行的流程。之后，可以在 tf.session 中向该计算图馈入数据，此时计算才真正发生。

——让我们开始逐步阅读代码——

（1）首先初始化一个新计算图。

import tensorflow as tf
tf.reset_default_graph()
lstm_graph = tf.Graph()

（2）计算图如何工作，应当在它的作用域内定义。

with lstm_graph.as_default():

（3）定义计算所需的数据。这里需要三个输入变量，都定义为 tf.placeholder，因为在构建计算图的阶段，我们还不知道它们的具体值。

  • inputs：训练数据 X，是形状为（数据样本数，num_steps，input_size）的张量；数据样本数未知，因此设为 None。在我们的情形中，训练会话期间它将是 batch_size。如果不清楚，请查看输入格式示例。
  • targets：训练标签 y，是形状为（数据样本数，input_size）的张量。
  • learning_rate：一个简单的浮点数。
    # Dimension = (
    #     number of data examples, 
    #     number of input in one computation step, 
    #     number of numbers in one input
    # )
    # We don't know the number of examples beforehand, so it is None.
    inputs = tf.placeholder(tf.float32, [None, config.num_steps, config.input_size])
    targets = tf.placeholder(tf.float32, [None, config.input_size])
    learning_rate = tf.placeholder(tf.float32, None)

（4）这个函数返回一个 LSTMCell，可以包含 dropout 操作，也可以不包含。

    def _create_one_cell():
        return tf.contrib.rnn.LSTMCell(config.lstm_size, state_is_tuple=True)
        if config.keep_prob < 1.0:
            return tf.contrib.rnn.DropoutWrapper(lstm_cell, output_keep_prob=config.keep_prob)

（5）如果需要，将单元堆叠成多个层。MultiRNNCell 帮助将多个简单单元按顺序连接，组成一个单元。

    cell = tf.contrib.rnn.MultiRNNCell(
        [_create_one_cell() for _ in range(config.num_layers)], 
        state_is_tuple=True
    ) if config.num_layers > 1 else _create_one_cell()

（6）tf.nn.dynamic_rnn 构建由 cell（RNNCell）指定的 recurrent neural network（循环神经网络）。它返回一对值（模型输出，状态），其中输出 val 的默认大小为（batch_size，num_steps，lstm_size）。状态指的是 LSTM 单元的当前状态，在这里没有使用。

    val, _ = tf.nn.dynamic_rnn(cell, inputs, dtype=tf.float32)

（7）tf.transpose 将输出的维度从（batch_size，num_steps，lstm_size）转换为（num_steps，batch_size，lstm_size）。然后选取最后一个输出。

    # Before transpose, val.get_shape() = (batch_size, num_steps, lstm_size)
    # After transpose, val.get_shape() = (num_steps, batch_size, lstm_size)
    val = tf.transpose(val, [1, 0, 2])
    # last.get_shape() = (batch_size, lstm_size)
    last = tf.gather(val, int(val.get_shape()[0]) - 1, name="last_lstm_output")

（8）定义隐藏层与输出层之间的权重与偏置。

    weight = tf.Variable(tf.truncated_normal([config.lstm_size, config.input_size]))
    bias = tf.Variable(tf.constant(0.1, shape=[config.input_size]))
    prediction = tf.matmul(last, weight) + bias

（9）我们使用均方误差作为损失指标，并使用 RMSPropOptimizer 算法进行梯度下降优化。

    loss = tf.reduce_mean(tf.square(prediction - targets))
    optimizer = tf.train.RMSPropOptimizer(learning_rate)
    minimize = optimizer.minimize(loss)

启动训练会话#

（1）要开始使用真实数据训练计算图，首先需要启动一个 tf.session。

with tf.Session(graph=lstm_graph) as sess:

（2）初始化已定义的变量。

    tf.global_variables_initializer().run()

（0）各训练轮的学习率应当事先计算好。这里的索引指训练轮的索引。

learning_rates_to_use = [
    config.init_learning_rate * (
        config.learning_rate_decay ** max(float(i + 1 - config.init_epoch), 0.0)
    ) for i in range(config.max_epoch)]

（3）下面每次循环完成一轮训练。

    for epoch_step in range(config.max_epoch):
        current_lr = learning_rates_to_use[epoch_step]
        
        # Check https://github.com/lilianweng/stock-rnn/blob/master/data_wrapper.py
        # if you are curious to know what is StockDataSet and how generate_one_epoch() 
        # is implemented.
        for batch_X, batch_y in stock_dataset.generate_one_epoch(config.batch_size):
            train_data_feed = {
                inputs: batch_X, 
                targets: batch_y, 
                learning_rate: current_lr
            }
            train_loss, _ = sess.run([loss, minimize], train_data_feed)

（4）最后不要忘记保存训练好的模型。

    saver = tf.train.Saver()
    saver.save(sess, "your_awesome_model_path_and_name", global_step=max_epoch_step)

使用 TensorBoard#

在没有可视化的情况下构建计算图，就像在黑暗中画画，既难以看清，又容易出错。Tensorboard 能方便地展示计算图结构与学习过程。可以看看这份动手实践教程，只有20分钟，但非常实用，还展示了几个现场演示。

简要总结

  • 使用 with [tf.name_scope](https://www.tensorflow.org/api_docs/python/tf/name_scope)("your_awesome_module_name"): 将为相似目标工作的元素组织在一起。
  • 很多 tf.* 方法接受 name= 参数。指定自定义名称，能够让阅读计算图轻松得多。
  • tf.summary.scalar 与 tf.summary.histogram 等方法有助于在迭代过程中跟踪计算图中变量的值。
  • 在训练会话中，使用 tf.summary.FileWriter 定义一个日志文件。
with tf.Session(graph=lstm_graph) as sess:
    merged_summary = tf.summary.merge_all()
    writer = tf.summary.FileWriter("location_for_keeping_your_log_files", sess.graph)
    writer.add_graph(sess.graph)

之后，将训练进度与汇总结果写入该文件。

_summary = sess.run([merged_summary], test_data_feed)
writer.add_summary(_summary, global_step=epoch_step)  # epoch_step in range(config.max_epoch)
