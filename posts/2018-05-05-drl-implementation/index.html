环境配置#

  1. 确保已经安装 Homebrew（软件包管理器）：
/usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
  1. 我建议为开发创建一个 virtualenv（Python 虚拟环境）。当多个项目的依赖要求冲突时，它会让事情简单得多；例如，一个项目使用 Python 2.7，而另一个只兼容 Python 3.5+。
# Install python virtualenv
brew install pyenv-virtualenv
# Create a virtual environment of any name you like with Python 3.6.4 support
pyenv virtualenv 3.6.4 workspace
# Activate the virtualenv named "workspace"
pyenv activate workspace

[*] 执行下面每一次新的安装操作时，请确保自己处于 virtualenv（Python 虚拟环境）中。

  1. 按照说明安装 OpenAI gym。进行最小安装时，运行：
git clone https://github.com/openai/gym.git 
cd gym 
pip install -e .

如果想尝试 Atari 游戏或其他高级软件包，请继续安装一些系统软件包。

brew install cmake boost boost-python sdl2 swig wget

对于 Atari，请进入 gym 目录并使用 pip 安装它。如果安装 ALE（arcade learning environment，街机学习环境）时遇到问题，这篇文章会很有帮助。

pip install -e '.[atari]'
  1. 最后，克隆这个“练习场”的代码并安装依赖。
git clone git@github.com:lilianweng/deep-reinforcement-learning-gym.git
cd deep-reinforcement-learning-gym
pip install -e .  # install the "playground" project.
pip install -r requirements.txt  # install required packages.

Gym（强化学习环境工具库）环境#

OpenAI Gym工具包提供一组物理仿真环境、游戏与机器人模拟器，我们可以尝试这些环境，并为其设计强化学习智能体。环境对象可以通过 gym.make("{environment name}" 初始化：

import gym
env = gym.make("MsPacman-v0")
