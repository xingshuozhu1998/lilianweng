R-CNN#

R-CNN（Girshick et al., 2014）是“Region-based Convolutional Neural Networks”（基于区域的卷积神经网络）的缩写。其主要思路包含两步。首先，使用 selective search（选择性搜索），找出数量适中、带有 bounding box（边界框）的目标区域候选，也称“region of interest”（感兴趣区域，RoI（感兴趣区域））。随后，从每个区域独立提取 CNN 特征，用于分类。

模型工作流程#

R-CNN 的工作方式可以概括如下：

  1. 在图像分类任务上 pre-train（预训练）一个 CNN 网络，例如在 ImageNet 数据集上训练 VGG 或 ResNet。该分类任务包含 N 个类别。

注意：预训练的 AlexNet 可以在 Caffe Model Zoo（模型库）中找到。我认为在 TensorFlow（机器学习框架） 中无法 找到它，但 TensorFlow-slim 模型 库提供了预训练的 ResNet、VGG 等模型。

  1. 通过 selective search 提出与类别无关的 region of interest（每张图像约 2000 个候选）。这些区域可能包含目标对象，而且大小各不相同。
  2. 将区域候选 warped（变形缩放）为 CNN 所要求的固定大小。
  3. 继续在变形后的候选区域上 fine-tuning（微调）CNN，使其区分 K + 1 个类别；额外的一个类别表示背景，即没有感兴趣的对象。在 fine-tuning 阶段，应使用小得多的 learning rate（学习率），并在 mini-batch（小批量）中过采样正例，因为大多数候选区域只是背景。
  4. 对于每个图像区域，通过 CNN 进行一次 forward propagation（前向传播），得到一个特征向量。该向量随后输入一个 binary SVM（二元支持向量机），这个分类器针对 每个类别独立训练。
    正样本是 IoU（intersection over union，交并比）重叠阈值 >= 0.3 的候选区域，负样本是其余无关区域。
  5. 为了减少定位误差，训练一个 regression（回归）模型，使用 CNN 特征预测 bounding box 的修正偏移量，以修正预测的检测窗口。

Bounding Box Regression#

给定预测 bounding box 的坐标 $\mathbf{p} = (p_x, p_y, p_w, p_h)$（中心坐标、宽度、高度）及其对应的 ground truth 框坐标 $\mathbf{g} = (g_x, g_y, g_w, g_h)$，让回归器学习两个中心之间的尺度不变变换，以及宽度和高度之间的对数尺度变换。所有变换函数都以 $\mathbf{p}$ 为输入。

$$ \begin{aligned} \hat{g}_x &= p_w d_x(\mathbf{p}) + p_x \\ \hat{g}_y &= p_h d_y(\mathbf{p}) + p_y \\ \hat{g}_w &= p_w \exp({d_w(\mathbf{p})}) \\ \hat{g}_h &= p_h \exp({d_h(\mathbf{p})}) \end{aligned} $$

使用这种变换的一个明显好处是，所有 bounding box 修正函数 $d_i(\mathbf{p})$（其中 $i \in \{ x, y, w, h \}$）都可以取 [-∞, +∞] 之间的任何值。它们要学习的目标为：

$$ \begin{aligned} t_x &= (g_x - p_x) / p_w \\ t_y &= (g_y - p_y) / p_h \\ t_w &= \log(g_w/p_w) \\ t_h &= \log(g_h/p_h) \end{aligned} $$

标准 regression 模型可以通过最小化带 regularization（正则化）的 SSE（平方误差和）损失来解决这个问题：

$$ \mathcal{L}_\text{reg} = \sum_{i \in \{x, y, w, h\}} (t_i - d_i(\mathbf{p}))^2 + \lambda \|\mathbf{w}\|^2 $$

这里 regularization 项至关重要，R-CNN 论文通过 cross validation（交叉验证）选择最佳的 λ。另外，并非所有预测 bounding box 都有对应的 ground truth 框。例如，如果两者没有重叠，执行 bbox regression 就没有意义。这里仅保留附近存在 ground truth 框且与其 IoU 至少为 0.6 的预测框，用于训练 bbox regression 模型。

常用技巧#

R-CNN 和其他检测模型通常会采用几种技巧。

Non-Maximum Suppression（非极大值抑制）

模型很可能为同一个对象找到多个 bounding box。Non-max suppression 帮助避免重复检测同一个实例。在得到同一目标类别的一组匹配 bounding box 后： 按置信分数对所有 bounding box 排序。 丢弃置信分数较低的框。 只要还有剩余的 bounding box，就重复以下操作： 贪心地选择分数最高的框。 跳过剩余框中与刚才选中的框具有较高 IoU（例如 > 0.5）的框。

Hard Negative Mining（困难负样本挖掘）

我们将不包含对象的 bounding box 视为负例。并非所有负例都同样难以识别。例如，只有纯空背景的框很可能是“easy negative（容易的负例）”；但如果框中包含奇怪的噪声纹理或部分对象，就可能难以识别，这些是“hard negative（困难的负例）”。

Hard negative 样本容易被误分类。我们可以在训练循环中明确找出这些 false positive（假阳性）样本，并将它们加入训练数据，以改善分类器。

速度瓶颈#

查看 R-CNN 的学习步骤，很容易发现训练 R-CNN 模型成本高且速度慢，因为以下步骤涉及大量工作：

  • 执行 selective search，为每张图像提出 2000 个区域候选；
  • 为每个图像区域生成 CNN 特征向量（N 张图像 * 2000）。
  • 整个过程分别涉及三个模型，几乎没有共享计算：用于图像分类和特征提取的 convolutional neural network；用于识别目标对象的顶层 SVM 分类器；以及用于收紧区域 bounding box 的 regression 模型。

Fast R-CNN#

为了加快 R-CNN，Girshick（2015）改进了训练流程，将三个独立模型统一为一个联合训练的框架，并增加共享的计算结果，这个框架称为 Fast R-CNN。它不再为每个 region proposal（区域提议）独立提取 CNN 特征向量，而是在整张图像上通过一次 CNN 前向计算集中提取，各个 region proposal 共享这个特征矩阵。随后，同一个特征矩阵分流到不同分支，用来学习目标分类器和 bounding box 回归器。计算共享由此加快了 R-CNN。

RoI Pooling#

这是一种 max pooling（最大池化），将任意大小 h x w 的图像投影区域内的特征转换为大小固定的小窗口 H x W。输入区域被划分为 H x W 个网格，每个子窗口的大小约为 h/H x w/W。随后，在每个网格中应用 max pooling。

模型工作流程#

Fast R-CNN 的工作方式概括如下；许多步骤与 R-CNN 相同：

  1. 首先，在图像分类任务上 pre-train 一个 convolutional neural network。
  2. 通过 selective search 提出区域（每张图像约 2000 个候选）。
  3. 修改预训练的 CNN：
    • 将预训练 CNN 的最后一个 max pooling 层替换为 RoI pooling 层。RoI pooling 层输出 region proposal 的固定长度特征向量。共享 CNN 计算很合理，因为同一张图像的许多 region proposal 高度重叠。
    • 将最后的 fully connected layer（全连接层）和最后的 softmax 层（K 个类别）替换为一个 fully connected layer，以及面向 K + 1 个类别的 softmax。
  4. 最后，模型分为两个输出层：
    • 一个面向 K + 1 个类别的 softmax 估计器（与 R-CNN 相同，额外的 1 个类别是“背景”），为每个 RoI 输出一个离散概率分布。
    • 一个 bounding-box regression 模型，为 K 个类别中的每个类别预测相对于原始 RoI 的偏移量。

损失函数#

模型针对结合两个任务（分类 + 定位）的损失进行优化：

| 符号 | 说明 | | $u$ | 真实类别标签，$ u \in 0, 1, \dots, K$；按照约定，统括所有背景的类别对应 $u = 0$。 | | $p$ | 每个 RoI 在 K + 1 个类别上的离散概率分布：$p = (p_0, \dots, p_K)$，通过对 fully connected layer 的 K + 1 个输出应用 softmax 计算得到。 | | $v$ | 真实 bounding box $ v = (v_x, v_y, v_w, v_h) $。 | | $t^u$ | 预测的 bounding box 修正量，$t^u = (t^u_x, t^u_y, t^u_w, t^u_h)$。参见 上文。 | {:.info}

损失函数将分类与 bounding box 预测的代价相加：$\mathcal{L} = \mathcal{L}_\text{cls} + \mathcal{L}_\text{box}$。对于“背景”RoI，$\mathcal{L}_\text{box}$ 被指示函数 $\mathbb{1} [u \geq 1]$ 忽略，该函数定义为：

$$ \mathbb{1} [u >= 1] = \begin{cases} 1 & \text{if } u \geq 1\\ 0 & \text{otherwise} \end{cases} $$

整体损失函数为：

$$ \begin{align*} \mathcal{L}(p, u, t^u, v) &= \mathcal{L}_\text{cls} (p, u) + \mathbb{1} [u \geq 1] \mathcal{L}_\text{box}(t^u, v) \\ \mathcal{L}_\text{cls}(p, u) &= -\log p_u \\ \mathcal{L}_\text{box}(t^u, v) &= \sum_{i \in \{x, y, w, h\}} L_1^\text{smooth} (t^u_i - v_i) \end{align*} $$

Bounding box 损失 $\mathcal{L}_{box}$ 应衡量 $t^u_i$ 与 $v_i$ 之间的差异，使用一个 robust（稳健） 的损失函数。此处采用 smooth L1 loss（平滑 L1 损失），据称它对异常值的敏感度较低。

$$ L_1^\text{smooth}(x) = \begin{cases} 0.5 x^2 & \text{if } \vert x \vert < 1\\ \vert x \vert - 0.5 & \text{otherwise} \end{cases} $$

速度瓶颈#

Fast R-CNN 在训练和测试时都快得多。然而，改进并没有非常显著，因为 region proposal 仍由另一个模型独立生成，而这一步成本很高。

Faster R-CNN#

一个直观的加速方案是将 region proposal 算法整合到 CNN 模型中。Faster R-CNN（Ren et al., 2016）正是这样做的：构建一个单一、统一的模型，由 RPN（region proposal network，区域提议网络）和 Fast R-CNN 组成，并共享卷积特征层。

模型工作流程#

  1. 在图像分类任务上 pre-train 一个 CNN 网络。
  2. 针对 region proposal 任务，对 RPN（region proposal network）进行 end-to-end（端到端）的 fine-tune，使用预训练的图像分类器初始化网络。正样本的 IoU（intersection-over-union）> 0.7，而负样本的 IoU < 0.3。
    • 在整张图像的卷积 feature map（特征图）上滑动一个小型 n x n 空间窗口。
    • 在每个滑动窗口的中心，同时预测多种尺度和宽高比的区域。一个 anchor（锚框）是（滑动窗口中心、尺度、宽高比）的组合。例如，3 个尺度 + 3 种宽高比 => 每个滑动位置有 k=9 个 anchor。
  3. 使用当前 RPN 生成的候选区域，训练一个 Fast R-CNN object detection 模型。
  4. 然后，使用 Fast R-CNN 网络初始化 RPN 训练。保留共享卷积层，只对 RPN 专属的层进行 fine-tune。此时，RPN 与检测网络已经共享卷积层！
  5. 最后，对 Fast R-CNN 独有的层进行 fine-tune。
  6. 如果需要，可以重复步骤 4–5，交替训练 RPN 与 Fast R-CNN。

损失函数#

Faster R-CNN 针对一个 multi-task（多任务）损失函数进行优化，与 Fast R-CNN 类似。

| 符号 | 说明 | | $p_i$ | anchor i 是对象的预测概率。 | | $p^*_i$ | anchor i 是否为对象的 ground truth 标签（二元）。 | | $t_i$ | 预测的四个参数化坐标。 | | $t^*_i$ | ground truth 坐标。 | | $N_\text{cls}$ | 归一化项，论文中设为 mini-batch 大小（约 256）。 | | $N_\text{box}$ | 归一化项，论文中设为 anchor 位置的数量（约 2400）。 | | $\lambda$ | 平衡参数，论文中设为约 10（使 $\mathcal{L}_\text{cls}$ 和 $\mathcal{L}_\text{box}$ 两项的权重大致相同）。 | {:.info}

Multi-task 损失函数结合了分类与 bounding box regression 的损失：

$$ \begin{align*} \mathcal{L} &= \mathcal{L}_\text{cls} + \mathcal{L}_\text{box} \\ \mathcal{L}(\{p_i\}, \{t_i\}) &= \frac{1}{N_\text{cls}} \sum_i \mathcal{L}_\text{cls} (p_i, p^*_i) + \frac{\lambda}{N_\text{box}} \sum_i p^*_i \cdot L_1^\text{smooth}(t_i - t^*_i) \\ \end{align*} $$

其中，$\mathcal{L}_\text{cls}$ 是针对两个类别的对数损失函数，因为通过预测一个样本是否为目标对象，可以轻松将多类别分类转为二元分类。$L_1^\text{smooth}$ 是 smooth L1 loss。

$$ \mathcal{L}_\text{cls} (p_i, p^*_i) = - p^*_i \log p_i - (1 - p^*_i) \log (1 - p_i) $$

Mask R-CNN#

Mask R-CNN（He et al., 2017）将 Faster R-CNN 扩展到像素级 image segmentation。关键是将分类与像素级 mask（掩码）预测任务解耦。基于 Faster R-CNN 框架，它添加了用于预测对象 mask 的第三个分支，与现有分类和定位分支并行。Mask 分支是一个应用于每个 RoI 的小型全连接网络，以像素对像素的方式预测分割 mask。

由于像素级分割比 bounding box 需要精细得多的对齐，Mask R-CNN 改进了 RoI pooling 层（称为“RoIAlign（对齐候选区域的特征采样方法） layer”），使 RoI 能更好、更精确地映射到原始图像的区域。

RoIAlign#

RoIAlign 层旨在修复 RoI pooling 中量化造成的位置错位。RoIAlign 去掉了粗糙的量化操作，例如使用 x/16 而不是 [x/16]，使提取的特征能正确对齐输入像素。Bilinear interpolation（双线性插值） 用于计算输入中浮点数位置上的值。

Loss Function#

Mask R-CNN 的 multi-task 损失函数结合了分类、定位和分割 mask 的损失：$ \mathcal{L} = \mathcal{L}_\text{cls} + \mathcal{L}_\text{box} + \mathcal{L}_\text{mask}$，其中 $\mathcal{L}_\text{cls}$ 和 $\mathcal{L}_\text{box}$ 与 Faster R-CNN 中相同。

Mask 分支为每个 RoI、每个类别生成一个 m x m 的 mask；总共有 K 个类别。因此，总输出的大小为 $K \cdot m^2$。由于模型尝试为每个类别学习一个 mask，各类别在生成 mask 时不存在竞争。

$\mathcal{L}_\text{mask}$ 定义为平均 binary cross-entropy（二元交叉熵）损失；如果该区域对应的 ground truth 类别为 k，就只包含第 k 个 mask。

$$ \mathcal{L}_\text{mask} = - \frac{1}{m^2} \sum_{1 \leq i, j \leq m} \big[ y_{ij} \log \hat{y}^k_{ij} + (1-y_{ij}) \log (1- \hat{y}^k_{ij}) \big] $$

其中，$y_{ij}$ 是该区域大小为 m x m 的真实 mask 中单元格 (i, j) 的标签；$\hat{y}_{ij}^k$ 是针对 ground truth 类别 k 学习的 mask 中同一个单元格的预测值。
