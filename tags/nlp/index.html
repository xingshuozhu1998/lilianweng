LLMs（大语言模型）中的 Extrinsic Hallucinations（缺乏外部事实依据的生成内容）

大语言模型中的 hallucination（幻觉）通常指模型生成不忠实于依据、捏造、前后不一致或毫无意义的内容。“幻觉”这个词在一定程度上被泛化为模型出错的各种情况。在这里，我想将幻觉问题缩小到模型输出是捏造的，而且既不以给定上下文为依据，也不以世界知识为依据的情况。 幻觉有两种类型： In-context hallucination（上下文内幻觉）：模型输出应当与上下文中的来源内容保持一致。Extrinsic hallucination（缺乏外部事实依据的幻觉）：模型输出应当以预训练数据集为依据。不过，由于预训练数据集规模庞大，为每次生成检索并识别冲突的成本过高。如果将预训练语料库视为世界知识的替代，我们实质上是在努力确保模型输出符合事实，并能由外部世界知识核实。同样重要的是，当模型不了解某个事实时，应当明确说明。本文聚焦于 extrinsic hallucination。为了避免幻觉，LLMs（大语言模型）需要（1）符合事实，以及（2）在适当情况下承认不知道答案。 ……

由 LLM（大语言模型）驱动的自主智能体

以 LLM（large language model，大语言模型）作为核心控制器来构建智能体，是一个很酷的想法。AutoGPT、GPT-Engineer 和 BabyAGI 等几个概念验证演示提供了富有启发性的例子。LLM 的潜力超出了生成优质文案、故事、文章与程序；它可以被视为一种强大的通用问题求解器。 智能体系统概览：在由 LLM 驱动的自主智能体系统中，LLM 充当智能体的大脑，并由几个关键组件加以补充。 规划：子目标与分解——智能体将大型任务拆分成更小、可管理的子目标，从而高效处理复杂任务。反思与改进——智能体可以对过去的行动进行自我批评和自我反思，从错误中学习，并改进后续步骤，从而提高最终结果的质量。记忆：短期记忆——我认为所有 in-context learning（在上下文示例中学习，参见 Prompt Engineering，提示工程）都在利用模型的短期记忆进行学习。长期记忆——长期记忆使智能体能够在很长的时间内保留并回忆（无限量的）信息，通常借助外部向量存储与快速检索来实现。工具使用：智能体学习调用外部 APIs（应用程序编程接口），获取模型权重中缺少的额外信息（权重在预训练后往往难以修改），包括当前信息、代码执行能力、专有信息来源的访问权限等。由 LLM 驱动的自主智能体系统概览。组件一：规划。复杂任务通常涉及许多步骤。智能体需要知道这些步骤是什么，并提前制定计划。 ……
